# 人生ノート — KAWAII LIFE 4.0

0歳から選択で育てる、日本語の人生設計ゲームです。移動アクションはありません。時間・お金・勉強・人間関係を配分し、最後に1000点満点の人生スコアを記録します。

## GitHub Pagesに置く

**このZIPの中身はすべてファイルです。フォルダはありません。** 画像もJavaScriptも `index.html` と同じ階層にあります。

1. ZIPを展開します。
2. GitHubリポジトリの `Add file → Upload files` で、展開した中のファイルをまとめて選び、リポジトリの一番上へアップロードします。
3. `Settings → Pages` で `Deploy from a branch`、`main`、`/ (root)` を選んで保存します。
4. GitHubが表示するURLを、スマホ・PCのブラウザで開きます。

ZIPそのものをアップロードしてもゲームにはなりません。展開した**中のファイル**を置いてください。古い版から更新するときは、先にゲームの設定からセーブJSONを書き出しておくと安心です。新しいファイルでルートの同名ファイルを置き換えます。

画像を含む **Jinsei_Note_Standalone.html** も別添しています。こちらは1ファイルだけで動きます。GitHub Pagesでは `index.html` に名前を変え、この1ファイルだけを置く方法も使えます。スマホのファイルアプリのプレビューはJavaScriptが動かないことがあるため、公開URLをブラウザで開いてください。

[GitHub公式の公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 計画の立て方

最初に親ガチャ／イージー／ミディアム／ハード、出生県、持ち味、寿命設定、進め方を選びます。授業・基本勤務以外の自由時間は12コマです。

1. 計画で時間を配分します。増やす前に別の活動を減らしてください。
2. 学生は学習プランと数学の段階を選びます。よく使う配分は「自分の学習プリセット」に保存できます。
3. できごとの選択肢を1つ選び、出願・資格・仕事・買い物などを必要に応じて追加します。
4. 「予定に必要な時間」を確認し、「この一年／4か月を過ごす」を押します。

4か月モードでも、その年度に選ぶ資格は2つまで、模試は3回まで、クイズは1問です。年間テーマ・長期プロジェクトは4月に決めます。教習・競プロ・楽器・旅行を詰め込むと、ほかの予定の時間が足りなくなります。

## 入試の読み方

- 国内825校に海外8校を追加。東京大学は6科類で出願します。
- 合格率は公表ボーダーとゲーム内の準備状況から計算する独自モデルです。実際の合格予測ではありません。大きく不足した場合は0%になり、最低20%の保証はありません。
- 学科の資料との対応が曖昧な場合は「同学部参考」、未対応の場合は「ゲーム設定」と表示します。全学科の正式な入試科目・配点・出願条件の網羅はしていません。
- 公表された科目型・科目数を保持し、分野と選択科目から判定用セットを作ります。慶應経済のA／B方式、早稲田政経の一般選抜は2027年度の公式科目変更を個別反映しています。
- 出願順は入学の希望順です。後期を前期より上にすると、前期の合格を辞退して後期へ進む場合があります。後期の合格は保証されません。
- 海外大学は語学・学力・活動実績を使う代表モデルです。国別の資格、SAT等の個別試験、ビザ、学費・奨学金の全制度は集約しています。

## 保存・スコア

自動保存は3枠。設定からセーブJSONを書き出し／読み込みできます。旧版セーブは読み込み時に移行します。ブラウザ・公開ドメイン・端末が変わる場合はJSONを使ってください。

人生スコアは資産450、幸福・健康250、関係150、社会貢献150を人望に応じて調整。結婚や子どもの人数だけでは加点しません。年表、結果の画像保存、最大20冊のアルバムがあります。

## データと検証

具体的な商品名を使っていますが、価格・耐用年数・効果はゲーム設定です。事故は航空統計を参考にした希少な抽選を実装し、病気・生活上のできごとは独自モデルを使います。**すべてのイベントに実測の発生確率を付けたものではありません。** 成功したプレイヤーを狙って失敗させる補正はありません。

詳細は [GAME_RULES.md](GAME_RULES.md)、[SOURCES.md](SOURCES.md)、[TEST_REPORT.md](TEST_REPORT.md) にまとめています。画像の権利は © Newtone、「Super kawaiii」の作者に帰属します。非公式の創作ゲームです。

## 開発者向け

配布物はビルド不要のHTML・CSS・JavaScriptです。Node 20以上では、依存パッケージなしで `npm test`、`npm run dev`、`npm run build` を実行できます。再ビルドしたZIPと単体HTMLは `release` に出力します。

主な処理：`engine.js`（進行・家計）、`next.js`（家庭・頻度・時間）、`admissions.js`（入試）、`admission-data.js`（公表資料の数値）、`quiz.js`（問題生成）。表示は `app.js` と `style.css` です。
